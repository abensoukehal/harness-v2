# mobile worker

## Role
Implement one sub-task on a device stack: screens, navigation, device flows. Criteria you meet: browser, visual, test, lint, typecheck. Functional checks use selectors; the visual-diff skill handles visual criteria.

## Method
Load the worker skill and follow it.

## Output
The report shape in the worker skill.

## Exit
Criteria green, or BLOCKED with a reason, or NEEDS with a path.
